# CLOUD PICK · AFTER DARK · VOL.03

가을밤의 종이 오리기풍 그래픽을 유지한, 단계별 UX와 인터랙티브 튜토리얼 버전입니다.
**인터넷에 배포한 상태는 아닙니다.** 이 패키지는 실제 플레이 가능한 클라이언트와 멀티플레이 서버 소스입니다.

## 바로 실행

혼자 체험하려면 `public/index.html`을 브라우저에서 엽니다. `직접 해보며 배우기`로 튜토리얼을 하거나, `시작하기 → 봇과 연습 → 연습 시작`을 선택하세요. 외부 그래픽·폰트·음원·JavaScript 라이브러리를 내려받지 않습니다. HTML에 그림과 로직이 모두 들어 있습니다.

친구와 연결하려면 Node.js 22 이상에서 프로젝트 폴더의 터미널을 열고 실행합니다.

```sh
node server.mjs
```

브라우저에서 `http://localhost:3000`을 엽니다. `시작하기 → 친구와 플레이 → 방 만들기`로 방을 만들고, 친구는 같은 서버 주소에서 `초대 코드로 참가하기`를 사용합니다. 같은 Wi-Fi의 다른 기기에는 서버 실행창의 네트워크 주소를 알려주세요. localhost는 다른 사람의 기기 주소가 아닙니다. 서로 다른 네트워크에서 플레이하려면 서버 배포가 필요합니다.

**기존 서버를 사용 중이라면:** 이 버전의 `public/index.html`만 기존 파일과 교체해도 됩니다. 서버 API 및 공통 게임 규칙은 이전 After Dark 버전과 동일합니다. 튜토리얼은 서버 방과 분리된 로컬 연습입니다.

## 이번 버전의 화면

| 화면 | 기본으로 보여주는 정보 | 필요할 때만 여는 정보 |
|---|---|---|
| 처음 | 분위기, 한 문장 규칙, 시작하기, 배우기 | 소리·움직임·상세 도움말 |
| 시작 준비 | 이름, 봇/친구 선택, 해당 시작 버튼 | 라운드·시간 설정 |
| 대기실 | 방 코드, 초대, 참가자, 게임 시작 | 방장 전용 방 설정 |
| 플레이 | 보드, 남은 시간, 점수·확정 상태, 내 선택·확정 | 메뉴 안의 기록·규칙·방 코드 |
| 결과 | 순위, 내 코인, 한 판 더 | 이번 판의 라운드 기록 |

## 튜토리얼

`첫 밤의 안내`는 4단계입니다. 1–3단계는 시간제한 없이 사용자가 이해한 뒤 다음으로 넘어갑니다. 4단계는 시작 버튼을 눌렀을 때만 10초가 흐릅니다. 건너뛰기와 재학습을 지원합니다.

1. 지정된 구름을 골라 혼자 2코인을 얻습니다.
2. 가운데 구름에서 친구와 겹쳐 0코인이 되는 예를 봅니다. 이전 코인은 잃지 않습니다.
3. 구름을 선택한 뒤 다른 곳으로 바꾸고, 직접 확정합니다.
4. 10초 안에 선택합니다. 미확정 시 마지막 선택, 미선택 시 0코인을 직접 확인할 수 있습니다.

완료하면 봇 연습 또는 친구와 플레이로 이동합니다. 완료 여부는 저장이 허용된 브라우저의 로컬 저장소에만 기록됩니다. 저장소를 사용할 수 없어도 튜토리얼과 게임은 동작합니다.

전체 문구, 단계별 노출 조건, 설계 의도는 `UX_TUTORIAL.md`를 참고하세요.

## 조작과 편의 기능

구름 클릭/터치 또는 숫자 1·2·3으로 선택하고, `선택 확정` 버튼 또는 Enter로 확정합니다. Tab과 Space로도 버튼을 조작할 수 있습니다. 메뉴는 오른쪽 위에 있습니다.

혼자 연습과 튜토리얼은 메뉴를 열면 일시정지합니다. 멀티플레이는 메뉴를 열어도 서버 시간이 계속 흐릅니다. 메뉴에 이 차이를 안내합니다. 소리와 움직임 줄이기 설정은 같은 메뉴에서 조절합니다.

## 수정과 빌드

```sh
node build.mjs
npm test
```

`build.mjs`가 `src/`의 소스에서 완성된 `public/index.html`을 만듭니다. 서버에 필요한 추가 npm 패키지는 없습니다.

```text
server.mjs                  HTTP API, SSE, 방/참가 토큰 관리
render.yaml                 아직 적용하지 않은 Render 배포 설정
build.mjs                   단일 HTML 빌드
public/index.html           바로 실행 가능한 완성본
src/game.js                 기존 공통 게임 규칙 (변경 없음)
src/prefix.js               앱 초기화, 동물 그림, 효과음
src/ui.js                   화면 단계, 튜토리얼, 입력, 네트워크
src/art.js                  기존 가을밤 보드 렌더링
src/timer.js                카운트다운 표시와 긴장감 연출
src/boot.js                 실행 루프, 연결, 재접속
src/styles.css              UI 스타일과 반응형 레이아웃
src/template.html           화면 구조
tests/protocol.test.mjs     실제 HTTP/SSE 4인 검증
tests/ux_browser_test.py    브라우저 UX 검증 (별도 테스트 환경 필요)
UX_TUTORIAL.md              UX 구조와 튜토리얼 대본
TEST_REPORT.md              검증 방법·결과·한계
DEPLOYMENT.md               다음 배포 작업을 위한 인계서
```

## 범위

서버의 방과 점수 및 랜덤매칭 대기열은 메모리에만 존재합니다. 서버가 재시작되면 사라집니다. 영구 저장, 계정, 랭킹, 대규모 서버 분산은 포함하지 않습니다. 한 개의 지속 실행 서버 프로세스로 운영해야 합니다.
