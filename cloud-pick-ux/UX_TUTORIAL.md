# CLOUD PICK · UX 구조 및 튜토리얼 대본

## 설계 방향

**“지금 해야 하는 선택은 하나. 나머지는 필요한 때에.”**

짙은 남색, 바랜 주황, 종이 질감, 동물 캐릭터, 조용하고 조금 수상한 문장은 유지했습니다. 변경 대상은 세계관이 아니라 정보의 노출 시점입니다. 아래 내용은 실제 HTML에 구현한 흐름이며, 사용자 조사로 효과가 입증되었다는 의미는 아닙니다.

감성적인 제목과 행동 버튼의 역할을 분리했습니다. “아무도 안 올 곳으로.”는 분위기를 맡고, 실제 버튼은 “선택 확정”으로 동작을 설명합니다. “봉인” 같은 비유만으로 버튼의 기능을 짐작하게 하지 않습니다.

## 정보의 깊이

### 기본 화면 — 지금 해야 할 행동

처음 화면에는 무엇을 하는 게임인지, 시작하는 방법, 배워보는 방법만 둡니다. 닉네임 입력, 방 코드, 모든 게임 규칙, 라운드 설정, 빈 점수표를 한꺼번에 펼치지 않습니다.

시작하기를 누르면 이름과 플레이 방식을 선택합니다. 봇 모드를 고르면 연습 시작만, 친구 모드를 고르면 방 만들기와 코드 참가만 보여줍니다. 이름은 필수가 아니며, 비어 있으면 “플레이어”로 시작합니다.

친구 방에서는 방 코드와 참가자를 보여줍니다. 초대 링크를 복사하고 참가자를 확인한 뒤 게임을 시작합니다. 봇 추가는 빈자리에서만 제공합니다. 방장 아닌 사람에게는 시작 버튼 대신 대기 상태를 설명합니다.

플레이 중에는 방 초대와 준비 설정을 치웁니다. 보드, 현재 라운드, 남은 시간, 네 명의 점수와 확정 여부, 나의 선택과 확정 버튼만 남깁니다. 확정하면 세 개의 활성 선택 버튼을 그대로 남겨두지 않고, 확정한 목적지와 대기 상태로 바꿉니다.

결과는 기존 화면을 작은 팝업으로 덮지 않고 별도의 결과 화면으로 전환합니다. 내 점수와 순위, 재대결이 중심이며 기록은 눌렀을 때 열립니다.

### 보조 화면 — 사용자가 요청한 정보

라운드 수와 선택 시간은 “규칙 변경/방 설정”에서 엽니다. 소리, 움직임 줄이기, 상세 도움말과 라운드 기록은 메뉴에 둡니다. 도움말도 긴 본문을 한 번에 펼치지 않고 질문별 접기/펼치기로 제공합니다.

상태별로 중요한 경고는 숨기지 않습니다. 서버가 없으면 친구 모드를 선택한 시점에 알려주며, 실패할 버튼을 누르고 난 뒤 기술 오류를 보여주지 않습니다. 접속 중 끊겼다면 선택 불가와 시간 계속 진행을 화면에서 알립니다.

### 학습 화면 — 설명을 행동으로 바꾸기

튜토리얼은 다른 플레이어의 방과 분리된 로컬 공간입니다. 한 단계당 하나의 새 개념을 배우고, 정답을 맞힐 때까지 불필요한 실패를 반복하도록 만들지 않습니다. 첫 두 단계는 미리 연출한 예시입니다. 실제 봇 경기의 선택 알고리즘과는 별개입니다.

## 튜토리얼 전체 대본

### 1/4 · 코인 획득

**진입 제목:** 첫 발은, 이쪽으로.

**안내:** 아래쪽 고양이가 너야. 번호가 표시된 세 구름 중, 왼쪽의 1번을 골라봐.

**보충:** 구름을 직접 누르거나, 아래 1번 버튼을 눌러도 돼.

**플레이어 행동:** 1번 구름을 클릭/터치하거나 숫자 1을 누릅니다. 이번 단계에서는 1번만 활성화합니다. 타이머 대신 천천히 해도 된다는 표시를 제공합니다. 별도의 확정 단계는 아직 가르치지 않으므로 선택하면 바로 예시를 공개합니다.

**연출:** 고양이가 혼자 구름에 도착하고 2코인을 얻습니다.

**피드백 제목:** 혼자 고르면, 전부 내 것.

**피드백:** 네가 고른 구름엔 아무도 없었어. 코인 2개가 주머니에 들어왔지.

**다음 행동:** 결과를 본 뒤 “다음으로”를 누릅니다. 자동으로 다음 설명으로 넘어가지 않습니다.

### 2/4 · 같은 구름에서 겹침

**진입 제목:** 가운데는, 모두의 욕심.

**안내:** 가운데엔 코인이 3개나 있어. 이번엔 2번 구름을 골라봐.

**보충:** 가운데 구름은 네 명 모두 고를 수 있어.

**플레이어 행동:** 가운데 2번을 고릅니다. 이 단계는 가운데만 활성화합니다.

**연출:** 친구 한 명도 가운데에 도착하게 미리 구성합니다. 둘이 같은 구름을 골라 이번 라운드 0코인을 얻습니다.

**피드백 제목:** 같은 생각. 둘 다 빈손.

**피드백:** 친구도 가운데를 골랐네. 같은 구름을 고른 둘 모두 이번에는 0코인이야.

**보충:** 이미 모은 2코인은 잃지 않아.

**다음 행동:** “다음으로”. 실패한 사용자에게 벌을 주는 단계가 아니라, 반드시 한 번 경험하는 규칙 예시입니다.

### 3/4 · 비밀 선택 → 변경 → 확정

**진입 제목:** 선택은, 너만의 비밀.

**안내:** 이제 세 구름 중 마음에 드는 곳을 골라봐. 이번엔 바로 이동하지 않을 거야.

**보충:** 다른 사람의 목적지는 공개 전까지 알 수 없어.

**첫 선택 후 제목:** 아직 마음을 바꿔도 돼.

**안내:** 이번엔 다른 구름으로 바꿔봐. 확정 전까지는 몇 번이든 다시 고를 수 있어.

**선택 변경 후 제목:** 좋아. 이제 네 선택을 믿어.

**안내:** 마음이 정해졌다면 ‘선택 확정’을 눌러봐. 확정한 뒤에는 바꿀 수 없어.

**플레이어 행동:** 어떤 구름이든 선택한 다음 다른 구름으로 한 번 바꿉니다. 변경을 경험하면 “선택 확정”을 활성화합니다. 이 변경 조건은 튜토리얼에서만 적용됩니다. 실제 경기에서는 첫 선택을 바로 확정할 수 있습니다.

**공개 후 제목:** 확정하면, 되돌릴 수 없어.

**피드백:** 다른 사람에게는 목적지가 아니라 확정 여부만 보여. 모두 확정하면 함께 공개해.

**다음 행동:** “다음으로”.

### 4/4 · 제한 시간

**진입 제목:** 마지막은, 10초 연습.

**안내:** 마지막으로 제한 시간 안에 골라보자. 준비되면 아래 버튼을 눌러.

**중요 안내:** 시간이 끝나면 마지막 선택이 적용돼. 아무것도 고르지 않으면 0코인.

**시작 버튼:** 10초 연습 시작.

이 버튼을 누르기 전에는 시간이 흐르지 않습니다. 이 단계의 연습 시간은 10초이며 실제 경기 시간은 방 설정을 따릅니다.

**진행 중 제목:** 10초 안에, 네 선택을.

**안내:** 세 구름 중 하나를 골라. 마음이 정해졌다면 바로 확정해도 돼.

**시간 종료 분기 A — 선택해둔 경우:** “마지막 선택으로 도착.” 확정하지 않아도 마지막 선택이 적용되었음을 보여줍니다.

**시간 종료 분기 B — 아무것도 선택하지 않은 경우:** “선택하지 않으면, 0코인.” 실전 점수에 영향을 주지 않는 연습임을 알리고 “10초 연습 다시 하기”를 제공합니다.

**종료 버튼:** 이제 알겠어.

### 완료

**제목:** 첫 밤을 지날 준비 끝.

**안내:** 이제 친구의 생각만 읽으면 돼. 실전에서는 설정한 라운드 동안 가장 많은 코인을 모으면 승리. 동점이면 함께 우승해요.

**주 행동:** 봇과 한 판.

**보조 행동:** 친구와 플레이.

처음 화면의 배우기 문구는 완료 여부를 저장할 수 있을 때 “튜토리얼 다시 해보기”로 바뀝니다. 완료 후 실제 경기를 시작하면 점수는 0부터 시작합니다.

## 예외 상황과 상호작용

| 상황 | 구현한 대응 |
|---|---|
| 규칙을 이미 아는 사용자 | 튜토리얼 없이 시작 가능. 튜토리얼의 건너뛰기는 종료 확인 후 처음으로 이동 |
| 메뉴를 읽는 초보 사용자 | 봇 연습·튜토리얼은 일시정지. 닫으면 남은 시간부터 재개 |
| 온라인 경기 중 메뉴 | 서버 시간을 멈추지 않음. 메뉴 안에 계속 진행된다는 안내 |
| 임시 선택 후 시간 종료 | 마지막 선택을 적용. 미선택이면 0코인 |
| 선택을 확정한 사용자 | 변경 버튼 대신 확정한 구름과 대기 상태 표시 |
| 경기 중 나가기 | 확인을 받음. 방장 이전과 남은 라운드 처리 설명 |
| 공유 주소의 서버 미연결 | 친구 모드에서 상황과 연결 방법을 제공. 혼자 연습 가능 |
| 키보드 사용자 | 1·2·3 / Enter / Tab / Space / Esc 지원, 초점 표시와 건너뛰기 링크 |
| 움직임에 민감한 사용자 | 움직임 줄이기 제공. 효과음 없이도 텍스트로 규칙과 결과 확인 |
| 작은 화면 | 설명은 보드 위, 조작은 아래. 네 점수는 압축해 상단 유지 |

## 유지한 게임 규칙

9개 구름의 3×3 배치, 각자 고를 수 있는 세 구름, 가운데 3코인, 모서리의 1·1·2·2코인, 겹치면 모두 0코인, 동시 공개, 점수 누적, 최대 4인 연결은 변경하지 않았습니다. 원작의 캐릭터나 외부 게임 자산을 새로 추가하지 않았습니다.

## 다음 사용성 검증의 기준

아직 실제 사용자를 대상으로 검증하지 않았습니다. 최초 사용자가 도움 없이 첫 선택을 할 수 있는지, ‘겹치면 코인을 잃는다’로 잘못 이해하지 않는지, 선택과 확정을 구분하는지, 친구 초대를 진행할 수 있는지를 관찰하는 것이 다음 단계입니다. 자동 테스트 통과를 사용성 검증 완료로 취급하지 않습니다.
