# Idol Long Run 0.4.1 — 기획 교차 디버깅

## 시작 불가 원인과 수정
이전 배포 index.html의 자바스크립트가 FOCUS 배열의 문자열 중간에서 끝났다. HTML은 보였지만 스크립트 전체가 파싱되지 않았고 시작 함수가 존재하지 않았다. 이번 빌드는 13개 JS 모듈, 2개 CSS, 완결된 HTML로 분리했다. 테스트한 파일의 Git blob 해시를 업로드 응답과 대조하고 검증판 verified-041.html과 ilr 모듈을 한 커밋으로 추가한다. 작업 중 발견된 동시 수정 9a01c692의 index.html, tested-v2.html, ilr-v2, season-r4와 기존 R&D 문서는 보존한다. 기존 CoinBattle 메인 브랜치, 다른 프로젝트 파일, Render 설정과 요금제는 변경하지 않는다.

## 기획 기준과 검증
- 맥락: 루트/성장/제안/평가마다 관련 조직과 화자 대사, 이름, 속마음 힌트를 먼저 보여준다. 공개 오디션 참가자에게 학원 전문반을 제안하지 않도록 루트 조건도 검사한다.
- 선택: 반년당 성장 계획 1회. 중간 제안이 없는 반년은 추가 레슨 선택 없이 결산한다. 핵심 평가만 2장 선택으로 압축한다. 포화된 능력치의 반복 훈련 대신 부족한 능력치 또는 팬덤/수익/회복을 제시한다.
- 결과: 즉시 효과와 반년 성장을 나눠 표시하고 확률 점수는 범위로 표시한다. 모든 결정 후 Before → After가 남는 결과 화면을 제공한다. 완료된 평가 점수는 다음 성장 결과로 섞이지 않는다.
- 방향: 24종 제안, 각 3가지 응답. 단계/나이/성장 축/기존 포지션/팬덤으로 조건을 나누고 한 인생에서 같은 제안은 반복하지 않는다. 버프는 성장·매출에 실제 적용되며 남은 반기를 표시한다.
- UI: 선택 화면은 한 화면, 기록·결과·정산은 스크롤 허용. 정보 패널을 열어도 선택지/난수/시간은 변하지 않는다. 연속 입력 중복, 모션 정리, 자동진행 시작·정지, 새 인생 취소를 검사한다.
- 경제: 가상 계약의 회사 배분 → 제작비 → 멤버 수 배분 → 개인 미정산 비용 상환 → 실제 정산. 실제 연예계 계약에 대한 일반화가 아니다.

## 실행
저장소 루트에서 실행한다. Node 22, Python Playwright, /usr/bin/chromium 환경에서 확인했다. 다른 환경은 browser.py와 interactions.py의 Chromium 경로를 변경한다.

```sh
node idol-qa/check.cjs
node idol-qa/simulation.cjs
SIZES='[[393,704],[360,640],[320,568],[430,820],[412,732]]' LAYOUT_ONLY=1 PART=final python idol-qa/browser.py
SIZES='[]' FLOW=vocal python idol-qa/browser.py
SIZES='[]' FLOW=dance python idol-qa/browser.py
SIZES='[]' FLOW=audition python idol-qa/browser.py
SIZES='[]' FLOW=casting python idol-qa/browser.py
python idol-qa/interactions.py
```

results/summary.json은 실제 실행 결과다. 엔진 1,000회 모두 종료, 이벤트 24종×3응답, 5개 뷰포트의 레이아웃 3,260개 검증, 4루트 DOM 버튼 조작으로 50세 종료, 별도 상호작용 15개 검증을 통과했다. 큰 assertion 수는 반복 불변조건 검사 횟수이며 독립된 기능 수가 아니다.

## 확인 범위와 남은 과제
브라우저 URL 탐색이 실행 환경 정책으로 차단되어 로컬 Chromium에 정확한 소스를 DOM 생성 후 defer 순서로 넣어 검사했다. 이 결과는 실제 S25/삼성 인터넷, 공개 URL에서의 브라우저 전체 플레이, 강제 다크 모드 검증을 뜻하지 않는다. 배포 후 Render의 live 상태와 커밋을 별도로 확인해야 한다.

생존 정책 봇 750회는 모두 레전드로 끝나 현재 후반 난이도는 쉬운 편이다. 무작위 정책 250회는 데뷔 전 종료 108, 레전드 42, 장수 88, 활동 중단 12회였다. 생존 정책 평균 결정은 96.2회이며 대사 넘기기와 결과 확인은 별도다. 사람이 10분 이내에 읽고 판단하는지는 아직 측정하지 않았다. 다음 기획 검토는 성공률 자체보다 반복 피로, 후반 성장 포화, 버프 종료의 인지성과 읽기 시간을 본다.
