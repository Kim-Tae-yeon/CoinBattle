# CLOUD PICK · AFTER DARK — Early Rewards 4.1.0

가을밤의 최대 4인 구름 선택 심리전입니다. 기존 랜덤 매칭·친구 방·봇 연습·4단계 튜토리얼은 유지하고, 큰 보상을 3라운드부터 등장시킵니다.

## 이번 변경

| 경기 구간 | 다섯 구름에 배치할 코인 |
|---|---|
| 1~2라운드 | `1 · 1 · 2 · 2 · 4` |
| 3라운드 이후 | `1 · 2 · 3 · 5 · 6` |

숫자는 위치 순서가 아닙니다. 중앙도 주변도 어떤 값을 받을 수 있습니다. 혼자 도착하면 표시된 금액 전부를 얻고, 겹치면 이번 라운드만 0코인입니다. 누적 코인은 보존합니다. 기본·랜덤 매칭은 **10라운드 / 선택 10초**입니다. 친구 방과 봇 연습의 라운드 설정은 유지합니다.

최대 보상 위치는 5개 위치를 비복원 셔플합니다. R3에 새 묶음을 시작하므로 R3~R7은 6코인이 다섯 위치를 한 번씩 방문합니다. R8~R10은 다음 묶음의 일부입니다. 따라서 전체 8개 고액 라운드의 기회가 모든 좌석에 정확히 같다고 보장하지 않습니다. 나머지 금액은 매 라운드 섞으며 미래 묶음은 서버 응답에 포함하지 않습니다.

구름 위에는 동전 아이콘과 실제 숫자를 표시합니다. 선택된 구름은 밝은 면·체크·테두리로 구분합니다. 중앙 고정 고액 안내는 제거하고, 튜토리얼의 중앙 3코인은 해당 연습의 예시라고 명시합니다. 아이템이나 추가 선택 단계는 없습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 실행하세요. 실행용 npm 패키지는 없습니다.

```sh
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`에 접속합니다. 빌드된 `public/index.html`을 직접 열면 튜토리얼과 봇 연습이 됩니다. 실제 랜덤 매칭은 여러 사람이 같은 Node 서버에 접속해야 합니다.

## 매칭과 시간

4명이면 연결 확인 후 출발합니다. 첫 대기자 기준 20초 후 2~3명이면 봇으로 빈자리를 채우고, 1명뿐이면 계속 기다립니다. 봇은 구분해 표시합니다. 별도 확장 대기열은 없습니다.

기본 단계는 준비 3초 → 선택 최대 10초 → 공개 7초이며, 전원 확정 시 선택은 조기 종료합니다. 랜덤 매칭의 첫 준비만 4초입니다. 10라운드 타이머 합은 일반 200초 / 랜덤 201초입니다. 대기열·로딩·자발적 튜토리얼·결과 화면 체류 시간은 별도입니다. 연구안의 강제 20초 소개·중간 휴식은 구현하지 않았고, 실제 경기시간 P95나 정확히 5분을 보장하지 않습니다.

## 수정과 배포

`src/`를 수정하고 `node build.mjs`로 빌드합니다. `src/app.js`와 `public/index.html`은 생성물입니다. 서버와 클라이언트를 함께 배포해야 합니다.

이 변경은 `feat/early-rewards-r3` 브랜치입니다. `main`에 병합하기 전에는 기존 Render 서비스에 반영되지 않습니다. 이 문서의 작성 시점에는 병합·배포를 하지 않았습니다. 기존 서비스의 빌드/실행 경로는 이 폴더입니다.

배포 후 확인 값: `/api/health`에서 `version: 4.1.0`, `matchmaking.rounds: 10`, `rewards.highStartRound: 3`, `rewards.high: [1,2,3,5,6]`, `revision`.

방·대기열·점수는 한 서버의 메모리에만 있습니다. 재시작 시 사라지며 다중 서버 간 상태 공유는 없습니다. 검증 범위는 `TEST_REPORT.md`를 참고하세요.
