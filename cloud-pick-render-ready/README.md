# CLOUD PICK · AFTER DARK 6.0.1

최신 기획 v0.38 적용판. 혼자 도착하면 코인 획득, 겹치면 이번 라운드는 0코인입니다. 누적 코인은 보존하며 동점은 공동 우승입니다.

## 실행

Node.js 22 이상, 추가 npm 패키지 없음.

```sh
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`으로 접속합니다. HTML 단독 실행은 튜토리얼·봇 연습만 지원하고, 멀티플레이는 같은 Node 서버 주소가 필요합니다.

## 기본 규칙

10라운드·선택 최대 10초. 확정 전 변경 가능, 전원 확정 시 조기 공개. 미확정은 마지막 선택, 완전 미선택은 서버의 합법 구름 균등 자동선택입니다. 명시적으로 나간 좌석의 미참여 처리는 별개입니다.

| 라운드 | 보상 구성 |
|---|---|
| 1–2 | low: 1·1·2·2·4 |
| 3–5 | low / mid / high 각 1회, 순서 무작위 |
| 6–10 | mid 2회 / high 3회, 순서 무작위 |

mid는 1·1·2·3·5, high는 1·2·2·3·6입니다. 최고 보상은 매 5라운드 다섯 보상 위치를 한 번씩 방문합니다. 중앙이 항상 최고는 아니며 5·6코인은 3라운드부터 등장할 수 있습니다.

## 랜덤 매칭

사람 4명이 모이면 연결 확인 후 시작합니다. 첫 대기자 기준 20초 후 사람이 2–3명이면 봇을 표시하고 빈자리를 채웁니다. 1명일 때는 다른 사람을 기다립니다. 취소·등록 재시도·새로고침 복구·경기 재접속·새 상대 찾기를 지원합니다. 친구 방과 봇 연습도 유지합니다.

## 첫 경기 후 확장

첫 전체 경기 종료 후 12초 동안 재경기를 제안합니다. 모든 인간 참가자가 동의하면 같은 방·좌석을 유지하고 점수·기록을 초기화합니다. 사람 4명·10라운드 방에서 전원이 미끼 확장에 동의할 때만 확장판입니다. 기본판 선택이 하나라도 있으면 전부 기본판, 무응답·나감이면 취소합니다. 봇 포함 방은 기본판만 가능합니다. 같은 멤버 재경기는 한 번만 제안하며 새 랜덤 방은 항상 기본판입니다.

미끼는 각자 경기당 1개. R5 결과 후 R6 적용, R8 결과 후 R9 적용 두 기회가 있습니다. 해당 보드에서 6초 배치·보류 → 2초 배치자·위치 동시 공개 → 10초 이동 선택으로 이어집니다. 이 라운드에는 별도 3초 보드 확인을 중복하지 않습니다. 모두 소모했다면 다음 미끼 창을 생략하고 일반 보드 확인을 사용합니다. R10에는 미끼가 없습니다.

미끼 구름에 혼자 도착한 사람이 +1을 얻습니다. 배치자 소유가 아니며 중첩 보너스는 총 +1, 확정한 토큰은 모두 소모됩니다. 충돌은 0, 효과는 한 라운드입니다. 배치 무응답은 보류이며 마지막 기회가 끝나면 남은 토큰은 만료됩니다. 큰 숫자는 보너스를 포함한 총액이고 `+1 포함`은 중복 지급이 아닌 상태 표시입니다.

## 정보·화면

상대 카드의 지속 전략 정보는 정확한 누적 코인뿐입니다. 과거 선택 로그·현재 목적지·확정 여부·확정 인원수·선두 강조는 없습니다. 신원·봇·연결 이상 표시는 유지합니다. 라운드 종료는 동시에 공개합니다. 개인 기록은 경기 종료 후 본인만 확인합니다. 미끼 배치자 신원은 2초 공개 뒤 사라지며 상대 토큰 보유량은 지속 표시하지 않습니다. 봇은 현재 보상에 `reward^0.9` 가중치만 사용합니다.

가을밤 종이 오리기풍, 높은 명도 대비와 동일한 보상 숫자 크기를 유지합니다. 최고 보상 글로우·선택 추천·빠른 선택 보너스·추가 초읽기 연출은 넣지 않습니다.
