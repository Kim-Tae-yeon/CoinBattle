# CLOUD PICK · AFTER DARK 6.0.0

세 구름 중 하나를 비밀리에 선택합니다. 혼자 도착하면 코인 획득, 겹치면 이번 라운드는 0코인입니다. 최신 기획 v0.37의 구현판입니다.

## 실행

Node.js 22 이상. 추가 npm 패키지 없이 실행합니다.

```sh
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`에서 접속합니다. HTML 단독 실행은 튜토리얼과 봇 연습용입니다. 랜덤 매칭은 모두 같은 Node 서버 주소에서 실행해야 합니다.

## 기본판

10라운드, 선택 최대 10초. 중앙 보상은 고정하지 않습니다.

| 라운드 | 보상 구성 |
|---|---|
| 1–2 | 1·1·2·2·4 |
| 3–5 | low / mid / high 각 1회, 순서 무작위 |
| 6–10 | mid 2회 / high 3회, 순서 무작위 |

low = 1·1·2·2·4, mid = 1·1·2·3·5, high = 1·2·2·3·6. 5·6코인은 3라운드부터 등장할 수 있고 5라운드까지 각각 한 번 나옵니다. 매 5라운드 묶음에서 최고 금액 위치가 다섯 보상 구름을 한 번씩 방문합니다.

확정 전에는 선택을 바꿀 수 있습니다. 모두 확정하면 즉시 공개합니다. 시간 종료 시 미확정은 마지막 선택을 적용하고, 끝까지 미선택인 참가 좌석에는 서버가 합법 구름 3개 중 하나를 균등 자동선택합니다. 자동선택도 같은 충돌·보상 규칙을 따릅니다. 명시적으로 나간 좌석의 기존 미참여 처리는 별개입니다.

R4·R8의 추가 4초 정지를 제거했습니다. 준비 최대 20초, 라운드별 보드 확인 3초·선택 최대 10초·결과 공개 7초입니다. 이전 누적 코인은 잃지 않으며 동점은 공동 우승입니다.

## 랜덤 매칭

사람 4명이 모이면 연결 확인 후 입장합니다. 첫 대기자 기준 20초가 지나고 사람이 2–3명이면 봇으로 빈자리를 채웁니다. 1명일 때는 다른 사람을 기다립니다. 봇은 표시되며 실제 사람으로 위장하지 않습니다.

취소, 새로고침 복구, 재접속, 경기 종료 후 새 상대 찾기를 지원합니다. 서버 시작이 느리면 연결을 자동 재시도합니다. 등록 응답이 유실되어도 같은 대기열 키로 재시도해 중복 참가를 막습니다. 친구 방과 봇 연습은 별도로 유지합니다.

## 기본판 뒤 같은 멤버 재경기

첫 전체 경기 종료 후 12초 동안 재경기 의사를 받습니다. 모든 인간 참가자가 동의하면 동일한 방·참가자·좌석을 유지하고 점수와 경기 기록을 초기화합니다.

4인 인간·10라운드 방에서는 `기본판으로` 또는 `미끼 확장 동의`를 고를 수 있습니다. 전원이 미끼에 동의할 때만 확장판입니다. 기본판 선택이 한 명이라도 있으면 전부 기본판으로 진행합니다. 봇 포함 방은 기본판만 재경기할 수 있습니다.

무응답·나감이 있으면 재경기를 취소하고 결과 화면에 남습니다. 계속할 사람은 `다시 매칭`으로 단일 공용 대기열에 들어갑니다. 같은 멤버 재경기는 한 번만 자동 제안합니다. 새 랜덤 방은 항상 아이템 없는 기본판입니다. 개인별 해금, 성능 차이, 확장 전용 대기열은 없습니다.

## 미끼 확장

모두 경기당 미끼 1개. **R5 결과 이후 R6 적용**, **R8 결과 이후 R9 적용** 두 번의 배치 기회가 있습니다. R10에는 미끼 창이 없습니다.

해당 보드를 보여준 뒤 6초 동안 자신의 합법 구름에 놓기를 확정하거나 보류합니다. 다음 2초에는 배치자와 위치를 동시에 공개합니다. 그 뒤 일반 10초 구름 선택을 시작합니다. 전원이 미끼를 소모했다면 뒤의 배치 창은 생략합니다.

해당 구름에 혼자 도착한 사람이 +1을 얻으며 배치자 소유가 아닙니다. 중첩은 총 +1, 확정한 미끼는 모두 소모됩니다. 충돌은 여전히0이며 효과는 해당 라운드만 유지됩니다. 배치 미확정·무응답은 보류입니다. 마지막 배치 기회가 끝나면 남은 미끼는 사용할 수 없습니다.

구름의 큰 숫자는 미끼 보너스를 포함한 총 보상입니다. `+1 포함` 표식으로 효과를 구분합니다. 배치자 신원은 2초 공개에만 나타나며 이동 선택 중 상대 미끼 보유량이나 배치 기록은 표시하지 않습니다.

## 정보와 화면

상대 카드에는 식별 정보와 정확한 누적 코인만 유지합니다. 상대 선택 기록·현재 확정 상태·확정 인원수·순위 강조는 없습니다. 네트워크 이상과 봇 표시는 유지합니다. 현재 라운드 종료의 동시 이동·충돌·획득 연출은 그대로입니다.

과거 history 응답은 요청자 자신의 결과만 포함하며 개인 기록은 경기 종료 후 확인합니다. 공개 장면을 기억하거나 별도로 기록하는 것까지 막는 정책은 아닙니다. 봇은 현재 공개 보상에만 `reward^0.9` 가중치를 사용하고 과거 위치·현재 상대 선택을 사용하지 않습니다.

가을밤 종이 오리기풍, 높은 명도 대비, 동일한 보상 숫자 크기를 유지합니다. 최고 보상 전용 글로우나 선택 추천은 추가하지 않습니다.
