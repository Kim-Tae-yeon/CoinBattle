# CLOUD PICK · AFTER DARK — Random Match 4.0.1

가을밤 배경에서 구름과 코인을 두고 서로의 선택을 읽는 최대 4인 웹 심리전입니다. 이 폴더가 Render에서 실제 실행하는 프로젝트입니다. 저장소 루트 README에 게임 규칙, 프로젝트 목표와 전체 기능이 정리되어 있습니다.

## 실행

```sh
node build.mjs
npm test
node server.mjs
```

Node.js 22 이상이 필요하며 실행용 외부 npm 패키지는 없습니다. `http://localhost:3000`에서 랜덤 매칭을 시작하세요. 빌드된 `public/index.html`만 직접 열면 튜토리얼과 봇 연습만 가능합니다.

## 공통 랜덤 매칭 규칙

- 사람 4명은 접속 확인 후 바로 출발합니다.
- 첫 대기자 기준 20초 뒤 사람 2~3명이면 빈자리를 봇으로 채웁니다.
- 혼자라면 다른 사람이 올 때까지 대기합니다. 봇은 사람처럼 숨기지 않고 표시합니다.
- 5라운드, 매 선택 10초입니다. 혼자 고른 구름만 코인을 얻고 겹치면 이번 라운드 0코인입니다.

`다른 방식으로 플레이`에서 친구 방과 봇 연습도 지원합니다. 튜토리얼, 메뉴, 명도 대비 개선은 모든 모드에 적용됩니다.

## 수정과 배포

소스는 `src/`에서 수정하고 `node build.mjs`로 HTML을 만드세요. `src/app.js`와 `public/`는 생성물이므로 직접 편집하지 않습니다. 랜덤 매칭은 `server.mjs`와 `src/matchmaker.mjs`도 필요하므로 HTML만 교체하지 마세요.

기존 Render 서비스는 저장소의 `main`에서 이 폴더로 이동해 빌드하고 실행합니다. 서비스 URL은 https://cloud-pick-after-dark-ux.onrender.com 입니다. `/api/health`의 `version: 4.0.1`, `protocol: 2`, `matchmaking.enabled: true` 및 `revision`을 확인하세요.

`HOST` 기본값은 `0.0.0.0`, `PORT` 기본값은 3000입니다. 플랫폼이 설정한 PORT를 우선 사용합니다. 선택 시간은 서버가 판정하고 SSE로 각 사용자에게 비공개 상태를 보냅니다. 매칭 상태 조회와 취소에는 탭에만 저장하는 임시 참가 키를 사용합니다.

방과 대기열은 메모리 전용입니다. 서버 재시작 시 사라지며 여러 서버가 대기열을 공유하지 않습니다. 계정, 전적 저장, 실력별 매칭, 대규모 운영 기능은 포함하지 않습니다. 검증 결과와 한계는 TEST_REPORT.md를 참고하세요.
