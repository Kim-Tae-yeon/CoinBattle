# CLOUD PICK · AFTER DARK 5.0.0

세 구름 중 하나를 비밀리에 선택합니다. 혼자 도착하면 표시된 코인을 얻고, 겹치면 이번 라운드는 0코인입니다. 누적 점수가 가장 높으면 승리합니다.

## 실행

Node.js 22 이상. 추가 npm 패키지가 필요하지 않습니다.

```sh
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`에서 실행합니다. HTML 파일 단독 실행은 튜토리얼과 봇 연습만 지원합니다.

## 적용 규칙

기본 및 랜덤 매칭은 10라운드, 선택 10초입니다. 중앙도 주변보다 적은 코인이 나올 수 있습니다.

| 라운드 | 다섯 보상 구름의 값 |
|---|---|
| 1–2 | 1·1·2·2·4 |
| 3–5 | 최대 4 / 5 / 6 보드를 각 한 번, 순서 무작위 |
| 6–10 | 최대 5 보드 두 번, 최대 6 보드 세 번, 순서 무작위 |

최대 5 보드: 1·1·2·3·5. 최대 6 보드: 1·2·2·3·6. 5와 6은 3라운드부터 등장 가능하며, 5라운드까지 각각 한 번 등장합니다. 매 5라운드 묶음에서 최고 금액은 다섯 보상 위치를 한 번씩 방문합니다. 모든 금액의 합이나 승률이 같다는 보장은 아닙니다.

시작 준비 최대 20초는 모두 준비 완료를 누르면 건너뜁니다. 각 라운드는 보드 확인 3초, 선택 최대 10초, 공개·결과 7초입니다. 4·8라운드 결과에는 4초를 더 줍니다. 전원 확정 시 선택은 조기 종료됩니다. 타이머를 모두 사용하는 기본 경기는 결과 진입까지 228초이며, 결과 확인 15초를 더한 설계 예산은 243초입니다. 실제 이용자의 P95나 대기열·로딩 시간은 검증한 수치가 아닙니다. 결과 화면은 강제로 닫히지 않습니다.

## 랜덤 매칭

4명이면 연결 확인 후 자동 입장합니다. 20초 후 2–3명이면 봇으로 빈자리를 채웁니다. 1명일 때는 다른 사람을 기다립니다. 사람 수와 봇 수는 구분합니다. 취소, 새로고침 복구, 경기 재접속과 종료 후 다시 매칭을 지원합니다. 친구 방과 봇 연습은 다른 방식으로 플레이에서 선택합니다.

## 화면

슬로건과 세계관 문구를 제거하고 규칙·조작·점수·연결 상태만 남겼습니다. 구름 위에는 실제 코인 수를 숫자로 표시합니다. 선택 상태는 밝은 면과 체크 표시로 구분합니다. 플레이 중에는 직전 라운드 결과만 요약하고, 전체 기록은 경기 결과에서 확인합니다. 가을밤 배경과 원본 동물 캐릭터는 유지합니다.

## 구조와 한계

`src/game.js`는 서버와 봇 연습 공통 규칙입니다. 10라운드 보상 순서는 서버의 Room 내부에만 있고, 온라인 snapshot에는 현재 보드와 공개된 과거만 포함됩니다. `src/ui.js`, `src/match-ui.js`, `src/art.js`를 수정한 뒤 다시 빌드하세요. `src/app.js`와 `public/index.html`은 생성물입니다.

서버는 HTTP 입력과 SSE 동기화를 사용합니다. 방과 대기열은 단일 프로세스 메모리이며 재시작하면 사라집니다. 동시 사용자를 여러 인스턴스로 나누지 마세요. 계정, 영구 전적, 아이템 확장과 랭크 매칭은 없습니다. 튜토리얼의 예시 보드는 규칙 학습용이며 실제 보상 순서와 분리되어 있습니다.

검증 범위는 TEST_REPORT.md를 참고하세요.
