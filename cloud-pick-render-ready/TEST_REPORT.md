# 4.0.1 배포 준비 검증

## 로컬 서버 테스트

`node build.mjs`, `node --check src/app.js`, `npm test`를 실행했습니다. Node.js 기본 테스트 러너는 **53개 통과, 0개 실패**를 보고했습니다. 상위 통합 시나리오 2개가 이 수에 포함됩니다.

- 대기열 단위 테스트 21개: 중복 참가, 취소 경합, 4인 준비, 2·3인 보충, 혼자 대기, 연결 만료와 복구, 그룹 분리, 자격 확인.
- 기존 친구 방 HTTP/SSE 검사 9개: 4인 참가, 비공개 선택, 충돌과 점수, 재접속, 이동 검증, 시간 종료, 방장 이전.
- 랜덤 매칭 HTTP/SSE 검사 13개: 코드 없는 4인 연결, 고정 규칙, 목적지 비공개, 5라운드 합산, 독립 재매칭, 취소와 세션 만료.
- 명도 대비 검사 8개: 본문·보조 문구·주 버튼·선택 버튼·타이머·비활성 문구와 주요 조작 테두리의 지정된 색상 조합.

20초 기준은 대기열 단위 테스트에서 가상 시간으로 검증합니다. 통합 테스트 일부는 1.8초의 대기 설정으로 실행 시간을 줄이며 실제 기본 설정은 20초를 유지합니다.

## 브라우저 UI 검사

튜토리얼·봇 연습·키보드 조작·메뉴 일시정지·320~1440px 화면 폭 등 45개 항목을 Chromium으로 통과했습니다. 이 실행 환경은 URL 탐색을 제한하므로 생성된 HTML을 `set_content`로 읽고 가상 시계와 메모리 저장소 fixture를 사용했습니다. 이는 실제 기기나 공개 인터넷의 네이티브 브라우저 연결 검증과 동일하지 않습니다.

## 해석상 주의

명도 검사는 지정된 주요 색상 쌍에 대한 계산이며 사이트 전체 WCAG 준수를 보증하지 않습니다. 자동 테스트 통과는 실사용자 사용성 조사, 실제 iPhone/Safari 검증, 대규모 부하 또는 인터넷 장시간 안정성 검증을 뜻하지 않습니다. 공개 배포 상태는 Render 배포 이력과 `/api/health`에서 별도로 확인해야 합니다.
