## 브라우저 검사의 정확한 범위

이 환경에서는 Chromium의 웹 주소 이동이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단됩니다. 제한을 변경하거나 우회하지 않았습니다. 빌드 HTML을 about:blank에 로드해 화면을 검사하고, 원본 HTML로 봇 연습과 네 단계 튜토리얼을 진행했습니다.

확장 화면에는 실제 Room에서 생성한 snapshot을 주입했고 UI 입력은 로컬 action mock으로 검사했습니다. 테스트 전용 hook과 mock은 배포 HTML에 포함되지 않습니다. 실제 서버 통신은 별도의 Node HTTP/SSE 클라이언트 4개로 검사했습니다. 따라서 **공개 주소에서 실제 브라우저 4개가 전 구간 플레이한 검증은 아닙니다.**

컨테이너의 외부 DNS도 접근이 안 됩니다. 공개 서비스 적용 여부는 GitHub commit과 Render 배포 이력으로 별도 확인해야 합니다.

## 시간

가상 시간의 기본판 결과 진입 220초, 확장판 최대 236초를 검산했습니다. 결과 확인 15초를 각각 더한 기획 예산은 235초·251초입니다. 조기 확정이 있는 HTTP/SSE 실제 테스트와 별개이며 인터넷 환경의 실제 사용자 P95 검증은 아닙니다.

## 재현

```sh
node build.mjs
npm test
# Playwright와 Chromium이 있는 별도 검증 환경:
python tests/score-only.browser.py
python tests/extension.browser.py
```

테스트 서버는 로컬 전용입니다. 프로덕션에 테스트 시간 가속, 강제 상대, 테스트용 미끼 해금 API를 추가하지 않았습니다.
