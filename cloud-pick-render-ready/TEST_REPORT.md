# CLOUD PICK 5.0.0 검증 기록

2026-09-15. 현재 배포 폴더의 소스를 바탕으로 변경하고 로컬 검증했습니다. 아래 내용은 사람 대상 사용성 실험 결과가 아닙니다.

## 실행한 검증

- Node 22.16.0: core-v5, matchmaker, protocol, random-protocol 테스트 53개 통과.
- 별도 contrast.test.mjs: 지정한 불투명 색상 쌍 8개 통과. 전체 사이트 WCAG 적합성 주장은 아닙니다.
- Chromium / Playwright: 로컬 HTML의 36개 UI 검사 통과. 320·390·768·1440px 가로폭에서 준비·선택·확정·메뉴, 가로 넘침 없음, 4단계 튜토리얼 완료를 확인했습니다. JavaScript 예외는 없었습니다.
- 실제 HTTP/SSE 클라이언트 4개로 10라운드 전체 랜덤 경기를 진행했습니다. 비공개 선택, 정확한 득점, 누적 점수, 재접속, 재매칭, 2인+봇 보충과 친구 방 회귀를 검증했습니다.
- 10,000개 seed에서 3–5라운드의 최대 4·5·6 순서, 후반 최대 5·5·6·6·6 순서와 5라운드별 최고 금액 위치 순환을 검증했습니다.
- 가상 시간으로 전원 미선택 시 228초에 결과 진입, 결과 확인 예산 포함 243초를 계산 검증했습니다. 실제 인터넷 지연의 P95 측정은 아닙니다.

## 재현

```sh
node build.mjs
npm test
```

브라우저 검사는 Playwright와 Chromium이 별도로 필요합니다. 테스트 환경의 URL 이동 정책 때문에 실제 HTML을 about:blank에 로드해 렌더링했습니다. URL 차단 정책을 변경하지 않았습니다. HTTP/SSE 통신은 브라우저 테스트와 분리해 Node 클라이언트로 확인했습니다.

## 검증하지 않은 범위

공개 서버에서 여러 실제 브라우저가 동시에 플레이하는 전 구간, Safari/iOS 실기기, 대규모 동시 접속, 악의적 자동화 대응, 실제 플레이의 밸런스와 재미는 이번 로컬 테스트로 입증하지 않습니다. 배포 상태와 코드 적용 여부는 Render 배포 이력으로 별도 확인합니다.

## 반영 내용

게임 버전 5.0.0. 10라운드·중앙 고정 보상 제거·3라운드부터 5/6 등장 가능·숫자 코인 표시·기능성 문구만 유지. 기존 랜덤 매칭의 서버 권위 및 사람/봇 구분 유지. 새 유료 자원이나 서비스 설정 변경 없음.
