# Early Rewards 4.1.0 — 검증 보고서

작성일: 2026-09-15. 적용 대상: `feat/early-rewards-r3`. 테스트는 로컬에서 수행했으며 GitHub CI나 공개 Render 검증 결과가 아닙니다.

## 실행 결과

`node build.mjs && npm test`: Node.js 22.16.0에서 **71개 통과 / 실패 0 / 건너뜀 0**, 약 104.6초.

실제 localhost HTTP/SSE 클라이언트 4개로 공개 매칭부터 10라운드 종료까지 진행했습니다. 모든 라운드 보상 풀, 충돌·단독 획득, 비공개 목적지, 누적 점수와 기록 일치, 재접속, 재매칭, 2인+봇 보충 및 친구 방 회귀를 포함합니다. 봇 보충 테스트만 대기 환경 변수를 1.8초로 단축했고 실제 기본값은 20초입니다.

`tests/rewards.test.mjs`의 추가 18개 항목은 100개 seed의 R1/R2와 R3 전환, 모든 보상 위치, 6코인 묶음의 순환, 미래 묶음 비노출, 5·6 정확한 지급, 충돌 시 과거 점수 보존, 시간초과, 중복 지급 방지, 잘못된 입력, 재접속·재경기 초기화, 서버와 로컬 룰 일치, 빌드 산출물을 확인합니다.

기존 명도 대비 테스트 8개도 통과했습니다. 전체 WCAG 준수나 실제 시각장애 사용자 검증을 의미하지 않습니다.

## 브라우저

Chromium에서 **64개 체크 통과**. 1360px·390px·320px 폭에서 R3 진입, 5·6 금액, 접근성 이름, 선택 표시, 실제 Canvas 픽셀 렌더링, 가로 넘침·JavaScript 오류 여부를 확인했습니다. 4단계 튜토리얼 완료, 봇 연습 10라운드 완료·총점·재경기 초기화도 확인했습니다. 스크린샷을 직접 검토했습니다.

테스트 환경에서 localhost 페이지 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었습니다. 따라서 브라우저 검증은 **변경하지 않은 빌드 HTML을 about:blank에 로드하고 Playwright clock으로 시간을 진행하는 오프라인 모드**로 수행했습니다. 네트워크 판정은 별도 Node HTTP/SSE 테스트 결과입니다. 이 둘을 온라인 브라우저 종단간 테스트로 표현하지 않습니다.

브라우저 재현(별도 Python Playwright 설치 필요):

```sh
node build.mjs
CHROMIUM_PATH=/usr/bin/chromium python tests/browser_rewards.py
```

Playwright 관리 Chromium을 사용하는 경우 `CHROMIUM_PATH`를 생략합니다. 보고서·스크린샷은 기본 `tests/reports/early-rewards/`에 생성됩니다.

## 미검증 및 범위

공개 배포, 실제 여러 기기의 인터넷 연결, Safari/iOS, 장시간 고지연·대규모 부하, 사람 플레이의 재미·밸런스, 실제 경기시간 P95는 검증하지 않았습니다. 기존 라이브 서비스와 main 브랜치를 이번 작업에서 변경하지 않았습니다.

R3~R7의 완전한 5라운드 묶음은 최대 보상 위치를 한 번씩 방문합니다. R8~R10은 일부 묶음이므로 전체 경기의 고액 노출이 정확히 같다는 주장은 하지 않습니다. 이번 보상 풀은 기존 기획 `[1,2,2,3,6]`이 아니라 사용자 요청의 5·6을 실제로 포함한 `[1,2,3,5,6]`입니다.
