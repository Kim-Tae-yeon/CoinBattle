# CLOUD PICK 6.0.1 — v0.38 검증 기록

2026-09-16. 실제 사용자 재미 실험이 아니라 코드·프로토콜·화면 회귀 검사입니다.

## 소스 기준과 변경

연결된 GitHub main `c5813e07dd59a72b06832320be0c0417e3b6c54e`의 README와 소스를 읽었습니다. 외부 DNS 제한으로 git clone을 사용할 수 없어, 현재 런타임의 5.2.0 ZIP에 해당 커밋의 변경을 복원하고 각 실행 소스의 Git blob SHA를 GitHub 값과 대조했습니다. 이 바이트 일치 기준에서 6.0.1 변경을 적용했습니다. 이전 작업의 테스트 결과를 이번 실행 결과로 간주하지 않았습니다.

변경은 미끼가 열리는 R6·R9의 중복 보드 확인 3초 제거, 버전·기획 메타데이터 갱신, 타이밍 회귀 검사와 문서 정리입니다. 선택 10초·일반 공개 7초·보상·랜덤 매칭·전원 합의·비밀 정보·아트는 유지합니다.

## 이번 런타임에서 실행한 결과

- Node.js 22.16.0: 기존 Node 테스트 89개 전부 통과, 실패0·건너뜀0. 실제 실행 약212.6초.
- v0.38 전용 테스트 6개를 별도 실행해 모두 통과. 합계 **95개 고유 테스트 통과**입니다.
- HTTP/SSE 자동 클라이언트 4개로 랜덤 매칭 → 10라운드 기본판 → 전원 미끼 동의 → 같은 방·좌석 확장판 10라운드 → 새 대기열 진입을 실제 로컬 서버 통신으로 확인했습니다.
- 친구 방, 2인+봇 보충, 취소 레이스, 비밀 선택·확정 마스킹, 재접속, 정확한 총점, 미끼 중첩+1, 1회 사용권, 보류, 배치 중 재접속과 중복 요청, R6/R9만 적용, R10 미발생을 확인했습니다.
- 10,000개 보상 seed 회귀 및 지정 색상 대비 검사도 포함합니다.
- 신규 6개는 R5/R8 결과에서 바로 미끼 배치 진입, 6초+2초 후 10초 선택, 기본판 3초 확인 유지, 모든 미끼 소모 시 일반 R9 복귀, 재접속에도 마감 고정, 조기확정·총 타이머를 검증합니다.
- Chromium 기본 UI·튜토리얼 검사107개 + 확장 화면·입력 검사110개, **217개 통과**, JavaScript 예외0개.
- 기본 화면320·360·390·768·1024·1440px, 확장 화면320·390·768·1440px에서 가로 넘침·점수 잘림·상대 기록 부재·선택·미끼·합의 버튼을 검사했습니다. 390px 이동/미끼 공개 화면도 직접 이미지로 확인했습니다.

## 범위 구분

브라우저의 로컬 HTTP 주소 이동을 시도했으나 `ERR_BLOCKED_BY_ADMINISTRATOR`가 반환됐습니다. 제한은 변경하지 않았습니다. 화면 검사는 about:blank에 빌드 HTML을 로드해 수행했습니다. 일부 확장 화면에는 실제 Room에서 생성한 snapshot과 테스트 전용 로컬 action mock을 사용했습니다. 원본 HTML의 봇 연습·튜토리얼은 별도 진행했습니다. 테스트 hook은 배포 HTML에 없습니다.

네트워크 검사는 브라우저 검사와 분리된 실제 Node HTTP/SSE 자동 클라이언트입니다. **공개 URL에서 실제 브라우저 4개로 전 구간 플레이한 검증은 아닙니다.** 배포 적용은 Render의 커밋·배포 상태로 별도 확인합니다.

## 정확한 시간

가상 시간 검산에서 기본판 결과 진입220초, 미끼 두 창이 열리는 확장판230초입니다. 결과 확인15초를 더하면235초·245초입니다. v0.38 본문의251초 산식에는 미끼가 대신하는 보드 확인3초×2가 중복되어 있어, 명시된 단계 규칙을 적용한 실제 산식으로 정정했습니다. 전원 조기확정 시 더 짧아집니다. 결과 화면은 강제 종료하지 않으며 대기열·로딩·경기 사이 시간·실제 사용자 P95는 이 수치에 포함되지 않습니다.
