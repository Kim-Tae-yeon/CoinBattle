## 재현

```sh
node build.mjs
npm test
# Playwright와 Chromium이 설치된 테스트 환경에서만:
python tests/score-only.browser.py
```

브라우저 테스트는 about:blank에 빌드 HTML을 로드했습니다. 일부 화면은 실제 Room으로 만든 snapshot을 테스트 전용 hook으로 주입했으며, 해당 hook은 배포 HTML에 포함하지 않습니다. 봇 연습과 튜토리얼은 원본 HTML로 별도 진행했습니다. HTTP/SSE 통신은 브라우저 검사와 분리한 Node 클라이언트 검사입니다.

## 정보 정책의 범위

선택 중 상대 카드에는 식별 정보와 누적 코인만 표시하고, 상대 확정 여부와 확정 인원수를 숨깁니다. 네트워크 이상 안내와 게임 시작 준비 완료는 유지합니다. 라운드 종료의 동시 이동·충돌·획득 연출은 그대로입니다. 따라서 공개 장면을 기억하거나 별도 저장하는 것까지 방지하는 정책은 아닙니다. 다음 라운드의 history 응답에는 요청자 자신의 과거 선택만 포함됩니다. 결과 화면의 내 기록도 본인 전용입니다. 서버 봇의 기존 공개 결과 기반 정책은 변경하지 않았습니다.

이번 검증은 완전한 네트워크 타이밍 부채널 차단, 실제 사용자 재미·공정성, 실기기 Safari/iOS, 대규모 동시접속, 공개 URL에서 실제 브라우저 4개의 전 구간 플레이를 입증하지 않습니다. 공개 배포 상태는 Render 배포 이력으로 별도 확인합니다.
