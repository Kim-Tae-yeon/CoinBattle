# CoinBattle

**CLOUD PICK · AFTER DARK**는 최대 4명이 구름 하나를 비밀리에 고르는 웹 멀티플레이 게임입니다. 혼자 도착하면 표시된 코인을 획득하고, 겹치면 이번 라운드는 0코인입니다.

**게임 주소:** https://cloud-pick-after-dark-ux.onrender.com

현재 실행 경로는 `cloud-pick-render-ready/`입니다. `cloud-pick-ux/`와 기존 ZIP은 이전 버전 보관본입니다.

## 프로젝트 목표

CoinBattle은 **간단한 선택 하나로 경쟁의 긴장감을 만드는 파티 게임**을 목표로 합니다. 더 많은 코인이 있는 구름을 노릴지, 다른 사람이 고르지 않을 구름으로 피할지 판단하는 과정이 핵심입니다. 모두의 선택이 동시에 공개되는 순간, 그 판단의 결과를 확인할 수 있습니다.

복잡한 조작보다 **상대의 선택을 예측하는 재미**에 집중합니다. 처음 접하는 플레이어도 직접 해보며 규칙을 익힐 수 있도록 체험형 튜토리얼을 제공하고, 각 화면에는 그 단계에서 필요한 정보와 행동을 우선 배치합니다. 가을밤의 차분한 분위기와 짧은 선택 시간의 긴장감이 공존하는 경험을 지향합니다.

## 5.1.0 적용 내용

상대 카드에 **이전 두 라운드의 공개 선택**을 시간순으로 표시합니다. R1은 기록 없음, R2는 한 개, R3부터는 최대 두 개입니다. 절대 위치·당시 구름의 코인 수·단독/겹침/미선택만 보여줍니다. 충돌해 0코인을 얻었더라도 당시 구름이 6코인이었다면 기록에는 6이 남습니다. 현재 선택·성격 판정·확률·추천은 표시하지 않습니다. 내 기록을 상단에 중복 추가하지 않고, 전체 개인 기록은 경기 종료 후에만 확인합니다.

기존 보상·매칭·시간 규칙은 유지합니다. 기본 및 랜덤 매칭은 **10라운드 / 선택 10초**입니다. 중앙 보상은 고정되지 않고 주변이 더 높을 수 있습니다. 1–2라운드는 최대 4, 3–5라운드는 최대 4·5·6 보드가 한 번씩 순서를 바꿔 등장합니다. 6–10라운드는 최대 5 보드 두 번과 최대 6 보드 세 번을 섞습니다. 5와 6은 3라운드부터 등장 가능하며 5라운드까지 각각 한 번 등장합니다.

구름의 코인 수를 큰 숫자로 표시하고, 선택 상태를 밝은 면과 체크 표시로 구분합니다. 화면의 슬로건과 세계관 문구는 제거한 상태를 유지합니다. 아이템 확장은 아직 포함하지 않습니다.

## 랜덤 매칭

**랜덤 매칭 → 닉네임 입력(선택) → 상대 찾기.** 사람 4명이 모이면 연결 확인 후 입장합니다. 첫 대기자 기준 20초 후 사람 2–3명이면 빈자리를 봇으로 채웁니다. 혼자라면 다른 사람을 기다립니다. 봇은 명시적으로 표시됩니다. 매칭 취소, 새로고침 복구, 재접속과 다시 매칭을 지원합니다. 친구 방과 봇 연습은 **다른 방식으로 플레이**에서 선택합니다.

게임 입장 후 최대 20초의 준비 시간을 줍니다. 모두 준비 완료를 누르면 바로 다음 단계로 갑니다. 매 라운드 확정 전에는 선택을 바꿀 수 있고, 전원 확정 또는 시간 종료 시 동시에 공개합니다. 미확정은 마지막 선택, 미선택은 0코인입니다. 이미 모은 점수는 잃지 않으며 동점은 공동 우승입니다.

## 실행 및 배포

Node.js 22 이상, 별도 npm 패키지 없음.

```sh
cd cloud-pick-render-ready
node build.mjs
npm test
node server.mjs
```

브라우저에서 `http://localhost:3000`에 접속합니다. HTML 단독 실행은 튜토리얼과 봇 연습만 지원합니다. 멀티플레이는 모두 같은 Node 서버 주소로 접속해야 합니다.

기존 Render 서비스의 명령:

```text
Build: cd cloud-pick-render-ready && node build.mjs
Start: cd cloud-pick-render-ready && node server.mjs
Health: /api/health
```

`version`, `revision`, `matchmaking.enabled`로 서버 적용 버전을 확인합니다. 보상 순서와 판정은 서버가 관리하며 다음 보드는 클라이언트에 미리 보내지 않습니다. 입력은 HTTP, 경기 동기화는 SSE입니다. `public/index.html`과 `src/app.js`는 빌드 생성물입니다.

## 범위

기본 경기 타이머는 전부 사용할 경우 결과 진입까지 228초이며, 결과 확인 15초를 더한 설계 예산은 243초입니다. 조기 준비·확정 시 짧아집니다. 대기열·로딩·자발적 튜토리얼은 별도이며 실제 P95 5분 이내를 측정한 것은 아닙니다.

방과 대기열은 단일 프로세스의 메모리에 저장됩니다. 서버가 재시작되면 초기화됩니다. 계정, 영구 전적, 랭크 매칭, 아이템, 대규모 분산 운영은 포함하지 않습니다.
