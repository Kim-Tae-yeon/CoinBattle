# CoinBattle

**CLOUD PICK · AFTER DARK**는 최대 4명이 구름 하나를 비밀리에 고르는 웹 멀티플레이 게임입니다. 혼자 도착하면 표시된 코인을 획득하고, 겹치면 이번 라운드는 0코인입니다.

**게임 주소:** https://cloud-pick-after-dark-ux.onrender.com

실행 경로는 `cloud-pick-render-ready/`입니다. `cloud-pick-ux/`와 이전 ZIP은 보관본입니다.

## 프로젝트 목표

간단한 선택 하나로 욕심·눈치싸움·역심리를 만드는 파티 게임입니다. 큰 보상을 노릴지, 상대를 피해 다른 구름으로 갈지 결정하고 동시에 결과를 확인합니다. 가을밤 종이 오리기풍 그래픽, 명도 대비, 필요한 시점에 필요한 정보만 보여주는 화면을 유지합니다.

## 6.0.0 — 기획 v0.37 적용

기본판은 **10라운드·선택 최대 10초**입니다. 중앙이 항상 가장 높지 않으며, 5·6코인은 3라운드부터 나올 수 있습니다. 상대 과거 선택 기록은 되살리지 않고, 상대 카드에는 식별 정보와 정확한 코인 총량만 유지합니다. 현재 선택·확정 상태·확정 인원수도 숨깁니다.

R4·R8 뒤 추가 4초 정지를 제거했습니다. 끝까지 미선택이면 서버가 합법 구름 3개 중 하나를 균등 자동선택하며, 이미 고른 구름이 있으면 마지막 선택을 적용합니다. 자동선택도 같은 충돌·보상 규칙을 따릅니다. 봇은 과거 위치 기억 없이 현재 공개 보상만 사용합니다.

첫 전체 경기 종료 후 **같은 멤버 재경기**를 12초 동안 제안합니다. 전원이 원하면 동일 방·좌석으로 이어갑니다. 사람 4명의 10라운드 방에서 **전원 미끼 확장 동의**일 때만 미끼를 적용하며, 한 명이라도 기본판을 고르면 모두 기본판입니다. 무응답·나감이면 취소되고, 계속할 사람은 다시 매칭할 수 있습니다. 봇 포함 방은 기본판 재경기만 가능합니다. 개인 성능 해금이나 확장 전용 대기열은 없습니다.

미끼는 각자 경기당 1개입니다. **R5→R6**, **R8→R9** 전환에서 6초 배치·2초 동시 공개 후 평소 구름 선택을 합니다. 혼자 도착한 사람이 +1을 받고, 같은 구름 중첩은 총 +1이며 확정한 토큰은 모두 소모됩니다. 이름과 위치는 공개 순간에만 보여주고 이동 선택에는 보너스 위치만 남깁니다. R10에는 미끼 창이 없습니다.

## 랜덤 매칭

**랜덤 매칭 → 상대 찾기.** 사람 4명이 모이면 연결 확인 후 입장합니다. 첫 대기자 기준 20초 이후 사람이 2–3명이면 봇으로 빈자리를 채웁니다. 혼자면 실제 상대를 기다립니다. 봇은 표시합니다.

매칭 취소·새로고침 복구·재접속·새 상대 찾기, 서버 시작 지연 시 연결 재시도, 등록 응답 유실 시 중복 없는 재등록을 지원합니다. 친구 방과 혼자 봇 연습도 유지합니다.

## 실행

Node.js 22 이상. 추가 npm 패키지 없음.

```sh
cd cloud-pick-render-ready
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`에서 접속합니다. HTML 단독 파일은 튜토리얼·봇 연습용입니다. 멀티플레이는 모두 같은 Node 서버 주소에서 열어야 합니다.

기존 Render 설정:

```text
Build: cd cloud-pick-render-ready && node build.mjs
Start: cd cloud-pick-render-ready && node server.mjs
Health endpoint: /api/health
```

`version`, `revision`, `design`, `matchmaking.enabled`로 적용 버전을 확인합니다. HTTP 입력·SSE 상태 동기화이며 `public/index.html`과 `src/app.js`는 빌드 생성물입니다.

## 시간과 한계

모든 타이머를 사용할 때 결과 진입까지 기본판 220초·확장판 최대 236초입니다. 결과 확인 15초를 더한 설계 예산은 **235초·251초**입니다. 조기 준비·확정 시 짧아지며, 결과 화면은 강제 종료하지 않습니다. 대기열·로딩·경기 사이 시간은 별도이고 실제 사용자 P95를 측정한 수치는 아닙니다.

단일 프로세스 메모리 서버이므로 재시작하면 방·대기열이 초기화됩니다. 계정·영구 전적·랭크·분산 운영은 포함하지 않습니다. 유료 자원이나 기존 요금제는 변경하지 않습니다.

로컬 Node 검사 **89개**, Chromium 화면 검사 **217개**를 통과했습니다. 실제 HTTP/SSE 클라이언트 4개로 기본판과 미끼 확장판 전체를 검증했으나, 환경 제한 때문에 공개 URL에서 실제 브라우저 4개의 전 구간 검증은 하지 못했습니다.
