# CoinBattle

**CLOUD PICK · AFTER DARK** — 세 구름 중 하나를 비밀리에 고르는 최대 4인 웹 게임입니다. 혼자 도착하면 코인을 얻고, 겹치면 이번 라운드는 0코인입니다.

**게임 주소:** https://cloud-pick-after-dark-ux.onrender.com

실행 경로는 `cloud-pick-render-ready/`입니다. `cloud-pick-ux/`와 이전 ZIP은 보관본입니다.

## 6.0.1 — 최신 기획 v0.38

가을밤 종이 오리기풍 그래픽과 명도 대비를 유지합니다. 기본판은 **10라운드, 선택 최대 10초**이며 전원이 확정하면 즉시 공개합니다. 상대 카드에는 식별 정보와 **누적 코인 총량만** 남기고, 과거 선택·현재 확정 여부·확정 인원수·순위 강조는 표시하지 않습니다. 실제 라운드 종료의 동시 공개는 유지합니다.

중앙이 항상 가장 높은 보상은 아닙니다. 5·6코인은 3라운드부터 등장할 수 있습니다. R4·R8의 추가 정지시간은 없고 일반 결과 공개는 7초입니다. 미확정은 마지막 선택을 적용하며, 끝까지 미선택이면 합법 구름 중 하나를 서버가 균등 자동선택합니다. 봇은 과거 선택을 기억하지 않고 현재 공개 보상만 사용합니다.

이번 업데이트에서는 **미끼가 열리는 R6·R9의 중복 3초 보드 확인을 제거**했습니다. 해당 보드에서 곧바로 6초 미끼 배치 → 2초 동시 공개 → 10초 이동 선택으로 진행합니다. 미끼가 없는 라운드는 기존 3초 보드 확인을 유지합니다.

## 랜덤 매칭과 확장

**랜덤 매칭 → 상대 찾기.** 사람 4명이면 연결 확인 후 입장합니다. 첫 대기자 기준 20초 이후 사람이 2–3명이면 빈자리를 표시된 봇으로 채웁니다. 혼자일 때는 실제 상대를 기다리며, 혼자 연습은 별도입니다.

첫 전체 경기 후 12초 동안 같은 멤버 재경기를 제안합니다. 사람 4명의 10라운드 방에서 전원이 **미끼 확장 동의**를 선택해야 확장판이 열립니다. 기본판을 선택한 사람이 있으면 전부 기본판으로 진행하고, 무응답이나 나감이면 재경기를 취소합니다. 봇 포함 방은 기본판 재경기만 가능합니다. 재경기는 같은 방·같은 좌석으로 한 번 이어지고 점수는 초기화합니다. 새 랜덤 방은 항상 기본판입니다. 개인별 성능 해금이나 확장 전용 대기열은 없습니다.

미끼는 경기당 1개, **R5→R6 / R8→R9**에 사용합니다. 혼자 도착한 사람이 +1을 받고, 중첩은 총 +1이며 확정한 미끼는 모두 소모됩니다. 배치자 신원은 공개 2초에만 표시하고, 이동 선택에는 중립적인 보너스 위치만 남깁니다. R10에는 미끼 창이 없습니다.

## 실행·배포

Node.js 22 이상. 추가 npm 패키지는 필요하지 않습니다.

```sh
cd cloud-pick-render-ready
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`에서 접속합니다. HTML 단독 파일은 튜토리얼·봇 연습용이며, 멀티플레이는 모두 같은 Node 서버 주소에서 열어야 합니다.

```text
Build: cd cloud-pick-render-ready && node build.mjs
Start: cd cloud-pick-render-ready && node server.mjs
Health endpoint: /api/health
```

`/api/health`의 `version: 6.0.1`, `design: v0.38`, `revision`, `matchmaking.enabled`로 적용 상태를 확인합니다. HTTP 입력·SSE 동기화를 사용하며, `public/index.html`과 `src/app.js`는 빌드 생성물입니다.

## 시간과 한계

모든 타이머를 쓰면 기본판 결과 진입은 220초, 미끼 두 창을 쓰는 확장판은 230초입니다. 결과 확인 15초를 더한 설계 예산은 **235초 / 245초**입니다. 이전 문서의 확장 251초에서 중복 보드 확인 3초×2를 뺀 값이며 선택시간은 줄이지 않았습니다. 조기 확정 시 더 짧아집니다. 대기열·로딩·경기 사이 시간은 별도이고 실제 사용자 P95를 측정한 수치는 아닙니다.

방과 대기열은 단일 프로세스 메모리에 있어 서버 재시작 시 초기화됩니다. 계정·영구 전적·랭크·분산 운영은 포함하지 않습니다. 기존 Render 무료 서비스·요금제·인스턴스 설정은 변경하지 않습니다.
