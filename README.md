# CoinBattle

**CLOUD PICK · AFTER DARK**는 최대 네 명이 구름의 코인을 두고 서로의 선택을 읽는 웹 멀티플레이 심리전입니다. 가을밤 종이 오리기풍 그래픽, 단계별 UX, 체험형 튜토리얼을 유지합니다.

> 큰돈이 있는 곳은 매번 다르다. 혼자 고르면 전부 내 것. 같은 구름에 모이면 모두 빈손.

## 4.1.0 변경안

**이 브랜치의 변경안이며 아직 기존 서비스에 배포하지 않았습니다.** 실제 수정 대상은 `cloud-pick-render-ready/`입니다. `cloud-pick-ux/`와 기존 ZIP은 보관본입니다.

| 구간 | 다섯 구름의 코인 |
|---|---|
| 1~2라운드 | `1 · 1 · 2 · 2 · 4` |
| 3라운드 이후 | `1 · 2 · 3 · 5 · 6` |

금액은 중앙과 주변 네 구름에 섞어서 배치합니다. 중앙이 항상 가장 비싼 곳은 아니고, 주변에서도 5·6코인을 얻을 수 있습니다. 기본 경기는 **10라운드 / 선택 10초**입니다. 아이템이나 추가 선택 규칙은 넣지 않았습니다.

## 코어 규칙

3×3 보드에서 내 옆의 구름 세 곳 중 하나를 몰래 고릅니다. 혼자 도착하면 표시된 코인을 전부 얻고, 두 명 이상 겹치면 이번 라운드 0코인입니다. 이미 모은 코인은 잃지 않습니다. 확정 전에는 선택을 바꿀 수 있고, 전원이 확정하거나 시간이 끝나면 함께 공개합니다. 미확정 상태에서는 마지막 선택이 적용되며, 아무것도 고르지 않았다면 0코인입니다. 최종 누적 코인이 가장 많으면 승리하고 동점은 공동 우승입니다.

## 플레이 방식

랜덤 매칭은 방 코드 없이 접속 순서대로 상대를 찾고 좌석을 섞습니다. 4명이 모이면 연결 확인 후 출발하고, 첫 대기자 기준 20초 후 2~3명이면 봇으로 빈자리를 채웁니다. 혼자라면 다른 사람이 올 때까지 기다립니다. 봇은 표시하며, 실력·지역별 매칭은 아닙니다. 취소·새로고침 복구·재접속·재매칭을 지원합니다.

`다른 방식으로 플레이`에서 친구 방과 봇 연습을 선택할 수 있습니다. 튜토리얼은 코인 획득 → 겹침 → 선택 변경·확정 → 제한 시간의 네 단계이며 앞 세 단계는 시간제한이 없습니다.

구름 클릭·터치 또는 `1`·`2`·`3`으로 선택하고 `Enter` 또는 **선택 확정**으로 확정합니다. 구름 위 실제 금액을 숫자로 표시하고 선택 상태는 밝은 면·체크·테두리로 구분합니다. 소리와 움직임 줄이기 설정을 제공합니다. 봇 연습·튜토리얼은 메뉴를 열면 일시정지하고, 온라인 경기는 계속 진행됩니다.

## 실행과 테스트

Node.js 22 이상에서 저장소 루트 기준:

```sh
cd cloud-pick-render-ready
node build.mjs
npm test
node server.mjs
```

실행용 외부 npm 패키지는 없습니다. 브라우저에서 `http://localhost:3000`에 접속하세요. `public/index.html` 단독 실행은 봇 연습·튜토리얼용입니다. 실제 멀티플레이는 모두 같은 Node 서버 주소에 접속해야 합니다.

10라운드 타이머 합은 일반 200초 / 랜덤 201초이며 전원 확정 시 더 빨리 진행합니다. 대기열·로딩·튜토리얼·결과 화면 체류 시간은 별도이고, 정확히 5분이나 실제 P95를 보장하지 않습니다. 시간을 채우기 위한 강제 안내·휴식은 추가하지 않았습니다.

## 기술 구성

HTML·CSS·JavaScript·Canvas 2D 클라이언트와 Node.js 서버입니다. 매칭 조회는 HTTP, 경기 상태 동기화는 SSE, 선택 입력은 HTTP를 사용합니다. 현재 상대 목적지와 미래 보상 묶음은 공개하지 않습니다.

`src/game.js`가 공통 규칙, `src/matchmaker.mjs`가 매칭, `src/ui.js`가 화면과 튜토리얼, `src/art.js`가 렌더링을 담당합니다. `node build.mjs`로 `public/index.html`과 `src/app.js`를 생성합니다. 원본 모듈을 수정하고 다시 빌드하세요.

최대 보상 위치는 다섯 위치를 한 번씩 방문하는 묶음으로 섞습니다. R3에 새 묶음을 시작합니다. 완전한 5라운드 묶음 밖의 일부 구간까지 정확한 기회 균등을 보장하지는 않습니다.

## 배포와 한계

기존 서비스 주소: https://cloud-pick-after-dark-ux.onrender.com

기존 Render는 main의 변경을 자동 배포합니다. 이번 변경은 `feat/early-rewards-r3`에만 있으며 병합 전에 기존 서비스 덮어쓰기를 확인해야 합니다.

```text
Build: cd cloud-pick-render-ready && node build.mjs
Start: cd cloud-pick-render-ready && node server.mjs
상태: /api/health
새 버전 확인: version=4.1.0, matchmaking.rounds=10, rewards.highStartRound=3
```

서버와 클라이언트를 함께 업데이트해야 합니다. 방·점수·대기열은 단일 프로세스 메모리 전용으로 재시작하면 사라집니다. 계정·영구 전적·신고·제재·실력 매칭·대규모 분산은 포함하지 않습니다.

자세한 실행 안내는 [프로젝트 README](cloud-pick-render-ready/README.md), 실제 검증과 한계는 [테스트 보고서](cloud-pick-render-ready/TEST_REPORT.md)를 참고하세요.
