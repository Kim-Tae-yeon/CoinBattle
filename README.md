# CoinBattle

**CLOUD PICK · AFTER DARK**는 구름 위의 코인을 두고 서로의 선택을 읽는 웹 멀티플레이 심리전 게임 프로토타입입니다. 가을밤의 차분한 색감과 종이 오리기풍 동물 캐릭터를 배경으로, 친구와 최대 4인으로 플레이하거나 봇과 혼자 연습할 수 있습니다.

> 혼자 고른 구름의 코인은 전부 내 것. 같은 구름에 모이면 모두 빈손.

아래 설명과 실행 방법은 저장소의 `cloud-pick-render-ready/` 소스를 기준으로 합니다.

## 게임 규칙

3×3으로 배치된 구름 보드에서 각 플레이어는 자기 옆의 구름 3개 중 하나를 비밀리에 선택합니다. 가운데 구름에는 3코인, 네 모서리에는 라운드마다 위치가 바뀌는 1·1·2·2코인이 놓입니다.

- **혼자 선택한 구름:** 표시된 코인을 획득합니다.
- **두 명 이상 선택한 구름:** 해당 구름을 고른 사람 모두 이번 라운드에 0코인을 얻습니다. 이미 모은 코인은 잃지 않습니다.
- **선택과 확정:** 확정 전에는 목적지를 바꿀 수 있으며, 모두 확정하거나 시간이 끝나면 동시에 공개합니다. 시간 종료 시 마지막 선택이 적용되고, 한 번도 고르지 않았다면 0코인입니다.

기본 설정은 **5라운드 / 선택 시간 10초**이며, 마지막에 누적 코인이 가장 많은 플레이어가 승리합니다. 동점이면 공동 우승입니다.

## 주요 기능

- **방 코드 기반 멀티플레이:** 같은 서버에 접속한 친구를 초대하고, 빈자리는 봇으로 채울 수 있습니다.
- **단계별 UX/UI:** 처음 화면, 시작 준비, 대기실, 플레이, 결과를 나누고 상세 규칙과 설정은 필요할 때 열도록 구성했습니다.
- **4단계 체험형 튜토리얼:** 코인 획득 → 같은 구름에서 겹침 → 선택 변경과 확정 → 제한 시간 순서로 직접 배우며, 처음 세 단계에는 시간제한이 없습니다.
- **PC·모바일 조작:** 구름 클릭·터치 또는 숫자 `1`·`2`·`3`으로 선택하고, `Enter` 또는 `선택 확정` 버튼으로 확정합니다. 소리와 움직임 줄이기 옵션을 제공합니다.

## 로컬 실행

**Node.js 22 이상**이 필요합니다. 저장소를 내려받은 뒤 저장소 루트에서 다음 명령을 실행하세요.

```sh
cd cloud-pick-render-ready
node build.mjs
node server.mjs
```

브라우저에서 `http://localhost:3000`에 접속합니다. `node build.mjs`가 소스를 합쳐 `public/index.html`을 생성하며, 빌드와 서버 실행에 별도 npm 패키지는 필요하지 않습니다.

혼자 연습하거나 튜토리얼을 확인할 때는 빌드된 `public/index.html`을 브라우저에서 직접 열어도 됩니다. **HTML 단독 실행은 멀티플레이 서버를 대신하지 않습니다.** 친구와 플레이하려면 모두 같은 Node 서버 주소로 접속해야 하며, 다른 기기에 초대할 때는 `localhost`가 아닌 서버의 접속 주소를 사용하세요.

## 기술 구성

프런트엔드는 HTML·CSS·JavaScript와 Canvas 2D로 구성되며, Node.js 서버가 방 관리와 게임 판정을 담당합니다. 클라이언트 입력은 HTTP 요청으로 전달하고, 상태 동기화는 SSE(Server-Sent Events)로 처리합니다. 다른 플레이어의 목적지는 결과 공개 전까지 비공개로 유지됩니다.

```text
cloud-pick-render-ready/
├─ server.mjs          # HTTP API, SSE, 방과 참가 세션 관리
├─ build.mjs           # 소스를 단일 HTML로 빌드
├─ package.json        # 실행 명령 및 Node.js 버전
├─ render.yaml         # Render 배포 설정
└─ src/
   ├─ game.js          # 서버·로컬 연습 공통 게임 규칙
   ├─ ui.js            # 화면 흐름, 튜토리얼, 입력과 네트워크
   ├─ art.js           # Canvas 보드와 캐릭터 렌더링
   ├─ styles.css       # UI 스타일과 반응형 레이아웃
   └─ template.html    # HTML 템플릿
```

위 트리는 주요 파일만 표시합니다. `public/index.html`과 `src/app.js`는 `node build.mjs` 실행으로 생성됩니다. 화면을 수정할 때는 원본 소스를 편집한 뒤 다시 빌드하세요.

## 프로토타입 범위

방과 점수는 서버 메모리에 저장되므로 서버를 재시작하면 사라집니다. 현재 구조는 한 개의 지속 실행 Node 프로세스를 전제로 하며, 계정·영구 기록·대규모 서버 분산을 제공하는 운영 서비스는 아닙니다.

추가 실행 안내는 [프로젝트 README](cloud-pick-render-ready/README.md), UX 구조와 튜토리얼 대본은 [UX 튜토리얼 문서](cloud-pick-ux/UX_TUTORIAL.md)를 참고하세요.
