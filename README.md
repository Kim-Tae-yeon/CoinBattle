# CoinBattle

**CLOUD PICK · AFTER DARK**는 최대 4명이 구름 하나를 비밀리에 고르는 웹 멀티플레이 게임입니다. 혼자 도착하면 표시된 코인을 획득하고, 겹치면 이번 라운드는 0코인입니다.

**게임 주소:** https://cloud-pick-after-dark-ux.onrender.com

현재 실행 경로는 `cloud-pick-render-ready/`입니다. `cloud-pick-ux/`와 기존 ZIP은 이전 버전 보관본입니다.

## 프로젝트 목표

CoinBattle은 **간단한 선택 하나로 경쟁의 긴장감을 만드는 파티 게임**을 목표로 합니다. 더 많은 코인이 있는 구름을 노릴지, 다른 사람이 고르지 않을 구름으로 피할지 판단하는 과정이 핵심입니다. 모두의 선택이 동시에 공개되는 순간, 그 판단의 결과를 확인할 수 있습니다.

복잡한 조작보다 **상대의 선택을 예측하는 재미**에 집중합니다. 처음 접하는 플레이어도 직접 해보며 규칙을 익힐 수 있도록 체험형 튜토리얼을 제공하고, 각 화면에는 그 단계에서 필요한 정보와 행동을 우선 배치합니다. 가을밤의 차분한 분위기와 짧은 선택 시간의 긴장감이 공존하는 경험을 지향합니다.

## 5.2.0 적용 내용

상대의 과거 선택 기록 화면을 제거했습니다. 경기 중 상대 카드에는 식별 정보와 **정확한 누적 코인**만 표시합니다. 상대의 현재 선택·확정 여부·확정 인원수도 표시하지 않습니다. 연결 끊김과 나감은 필요한 연결 안내로 유지합니다. 준비 단계의 준비 완료는 선택 확정과 구분합니다.

라운드 종료 시 **모두 함께 이동하는 결과 공개 연출**은 유지합니다. 공개된 장면을 기억하거나 직접 기록하는 것을 막는 기능은 아닙니다. 다음 라운드에는 상대 선택을 다시 볼 수 있는 기록 UI가 없고, 서버의 과거 `history` 응답에도 요청자 자신의 결과만 포함됩니다. 전체 개인 기록은 경기 종료 후 **내 기록 보기**에서 확인합니다. 봇의 기존 공개 결과 기반 정책은 변경하지 않았습니다.

기본 및 랜덤 매칭은 **10라운드 / 선택 10초**입니다. 중앙 보상은 고정되지 않고 주변이 더 높을 수 있습니다. 1–2라운드는 최대 4, 3–5라운드는 최대 4·5·6 보드가 한 번씩 순서를 바꿔 등장합니다. 6–10라운드는 최대 5 보드 두 번과 최대 6 보드 세 번을 섞습니다. 5와 6은 3라운드부터 등장 가능하며 5라운드까지 각각 한 번 등장합니다.

구름의 코인 수를 큰 숫자로 표시하고, 내 선택은 밝은 면과 체크 표시로 구분합니다. 가을밤 아트와 명도 대비를 유지합니다. 슬로건·세계관 문구·아이템 확장은 추가하지 않습니다.

## 랜덤 매칭

**랜덤 매칭 → 닉네임 입력(선택) → 상대 찾기.** 사람 4명이 모이면 연결 확인 후 입장합니다. 첫 대기자 기준 20초 후 사람 2–3명이면 빈자리를 봇으로 채웁니다. 혼자라면 다른 사람을 기다립니다. 봇은 명시적으로 표시됩니다. 매칭 취소, 새로고침 복구, 재접속과 다시 매칭을 지원합니다. 친구 방과 봇 연습은 **다른 방식으로 플레이**에서 선택합니다.

입장 후 최대 20초의 준비 시간을 주며 전원 준비 완료 시 진행합니다. 확정 전까지 선택을 바꿀 수 있고, 전원 확정 또는 시간 종료 시 동시에 공개합니다. 미확정은 마지막 선택, 미선택은 0코인입니다. 누적 점수는 잃지 않으며 동점은 공동 우승입니다.

## 실행 및 배포

Node.js 22 이상, 별도 npm 패키지 없음.

```sh
cd cloud-pick-render-ready
node build.mjs
npm test
node server.mjs
```

`http://localhost:3000`에서 실행합니다. HTML 단독 실행은 튜토리얼과 봇 연습만 지원합니다. 멀티플레이는 모두 같은 Node 서버 주소로 접속해야 합니다.

```text
Build: cd cloud-pick-render-ready && node build.mjs
Start: cd cloud-pick-render-ready && node server.mjs
Health: /api/health
```

`version`, `revision`, `matchmaking.enabled`로 서버 적용 버전을 확인합니다. 입력은 HTTP, 경기 동기화는 SSE입니다. 다음 보드는 서버 내부에만 보관합니다. `public/index.html`과 `src/app.js`는 빌드 생성물입니다.

## 범위

기본 경기 타이머를 모두 사용하면 결과 진입까지 228초입니다. 결과 확인 15초를 더한 설계 예산은 243초이며 조기 준비·확정 시 짧아집니다. 대기열·로딩·자발적 튜토리얼은 별도이며 실제 P95 5분 이내를 측정한 것은 아닙니다.

방과 대기열은 단일 프로세스 메모리입니다. 서버 재시작 시 초기화됩니다. 계정·영구 전적·랭크 매칭·아이템·대규모 분산 운영은 포함하지 않습니다.
