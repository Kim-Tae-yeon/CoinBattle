실행 진입점: `tested-v2.html` (v2.0.0). 작업 중 확인된 동시 수정 `d3cfe7730700fb46bff50926958ba1de9668da76`의 기본 `index.html`, `rnd-motion-v1.html`, `season-r4`는 덮어쓰지 않는다. 이번 검증판과 회귀 테스트만 추가한다.

## 실제 장애 원인

이전 배포 커밋 `0ee28729f56dbfcf0a016b943013e200dc50d16f`의 `index.html`은 FOCUS 배열의 문자열 중간에서 끝났다. JavaScript 구문이 완결되지 않았고 `showRoutes()` 등 시작 버튼에 연결된 함수도 들어 있지 않았다. 서버의 배포 성공은 클라이언트 JavaScript 실행 성공을 뜻하지 않았다. 사용자 캐시 문제가 아니었다.

이번 수정은 화면, 데이터, 규칙, 진행, 입력 처리를 완결된 파일로 분리했다. 각 파일의 구문을 검사하고, 테스트한 로컬 파일의 Git blob SHA와 업로드 응답의 SHA를 대조한 뒤 하나의 tree/commit으로 공개 브랜치에 반영한다. main 브랜치와 다른 게임 서비스는 수정하지 않는다.

## 실행한 검증

- 모델: 4개 루트를 순환한 시드 800개. 전부 유한한 단계 안에 엔딩 도달. 탈락 엔딩도 정상 종료에 포함한다.
- 이벤트: 22개 이벤트의 66개 선택을 각각 실행했다.
- 모델 assertion: 1,832,958회. 수치 유한성·범위·반년 증가·미리보기 일치·중복 처리 거절·버프 만료·조건부 사건·정산 보존을 포함한다.
- Chromium: 258개 레이아웃 검사, 실제 UI 버튼으로 4개 루트의 전체 커리어 진행, 별도 UI assertion 15개. 오류와 실패 목록은 비어 있다.
- 화면 크기: 360×600, 384×640, 393×720, 412×780, 430×850 CSS px. 선택지의 화면 이탈, 내용 잘림, 가림, 44px 미만 카드 높이, 페이지 스크롤을 검사했다.
- 추가 브라우저 검사: 9개. 실제 자동 시연 버튼/타이머로 엔딩까지 80개 선택, 중복 입력 잠금, 정상 모션의 파티클 생성/정리, 저장 거절, 저장 직렬화/복원, 이름 이스케이프, 모듈 누락 시 오류 표시를 포함한다.

## 재실행

저장소 루트에서:

```sh
node ilr-v2/qa-test.cjs
```

외부 패키지 없이 모델 회귀 검증을 실행하고 `ilr-v2/model-results.json`을 생성한다. 브라우저 검사는 로컬 Chromium과 Playwright에서 실행했다. 실행 환경이 외부 URL 탐색을 차단하여 같은 테스트 소스를 인라인으로 묶은 문서를 `page.set_content`로 로드했다. 모델 진행은 모킹하지 않았고 실제 버튼 핸들러를 실행했다. 자동 시연의 긴 타이머는 가상 시계로 진행했다.

## 검증 범위와 남은 과제

공개 URL의 브라우저 로딩과 S25 실기기, 실제 터치/진동, 사람의 10분 플레이시간은 이 환경에서 검증하지 못했다. 저장 직렬화/복원 검사는 Storage 호환 어댑터를 사용했으며 브라우저 실제 영구 저장 검증과 구분한다. Render의 live 상태는 별도로 확인하며, 서버 상태만으로 클라이언트 실행을 검증했다고 하지 않는다.

이번 버전은 작동하는 반년제 R&D 빌드다. 자동 정책에서 장수 엔딩 비중이 높아 난이도와 장기 성장 상한은 후속 밸런스 과제다. 정산은 게임 내 가정이며 실제 업계의 모든 계약을 일반화하지 않는다. 기존의 모든 월말평가/관계/스캔들 아이디어를 완성했다고 주장하지 않는다.
